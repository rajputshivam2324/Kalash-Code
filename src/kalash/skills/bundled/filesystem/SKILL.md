# filesystem

Use glob/list/search to narrow paths, then read selected line ranges. Read before edit;
exact edits must match uniquely. Use write for new text files and shell for an authorized
move or copy. Keep source and destination explicit; inspect conflicts first.
For binary artifacts, load the appropriate format skill. Never dump a repository into
context. Verify the resulting file/diff rather than trusting command success.
