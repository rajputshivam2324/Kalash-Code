# git

Use shell for git status --short, git diff, git log and git blame with narrow paths.
Preserve pre-existing edits. Never infer a clean baseline from an old session note.
Create commits, branches or pushes only within the user's authorized task. Check staged
paths before committing. Do not reset, clean or force-push to resolve routine uncertainty.
Record the exact revision when comparing external implementations.
