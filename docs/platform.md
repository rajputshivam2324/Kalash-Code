# Platform

> **Status:** normative.

Cross-platform behaviour, install lifecycle, configuration validation, internationalization, and time handling.

---

## 1. Capability Matrix

| Capability | Linux ≥5.13 (Landlock) | Linux older (bubblewrap) | macOS | Windows 11 | WSL2 |
|------------|:----------------------:|:------------------------:|:-----:|:----------:|:----:|
| Sandbox: filesystem | Full | Full | Full | Full | Full ¹ |
| Sandbox: network | Full | Full | Partial ² | Partial ³ | Full ¹ |
| Sandbox: process isolation | Full | Full | Full | Full | Full ¹ |
| Process-tree termination | Full (cgroups) | Full (cgroups) | Full (process groups) | Full (Job objects) | Full ¹ |
| Resource limits (CPU/RAM) | Full (cgroups v2) | Partial (rlimit) | Partial (rlimit) | Full (Job objects) | Full ¹ |
| OS keyring | Full (Secret Service) | Full (Secret Service) | Full (Keychain) | Full (Credential Manager) | Full ⁴ |
| TUI truecolor | Full | Full | Full | Full (Windows Terminal) | Full |
| Signals (SIGTERM, SIGINT) | Full | Full | Full | Partial ⁵ | Full |
| File watching (inotify/FSEvents/ReadDirectoryChanges) | Full | Full | Full | Full | Partial ⁶ |
| Atomic rename | Full | Full | Full | Full ⁷ | Full |
| Symlinks | Full | Full | Full | Partial ⁸ | Full |
| Case sensitivity | Full (byte-oriented) | Full | None (case-insensitive preserving) | None (case-insensitive preserving) | Full |
| sqlite-vec | Full | Full | Full | Full | Full |
| ONNX Runtime | Full | Full | Full | Full | Full |
| Desktop notifications | Full (notify-send/D-Bus) | Full (notify-send) | Full (osascript) | Full (toast XML) | None ⁹ |

**Footnotes:**
1. WSL2 uses Linux kernel; Landlock if ≥5.13, else bubblewrap.
2. macOS Seatbelt: network filtering at socket level; no per-destination granularity without PF rules.
3. Windows AppContainer: ACL-based network isolation; per-host filtering requires Windows Firewall rules.
4. WSL2 accesses Windows Credential Manager via `wincred` helper.
5. Windows uses `CTRL_C_EVENT` / `CTRL_BREAK_EVENT`; no SIGTERM equivalent — Job object termination used.
6. WSL2 inotify does not fire for changes made from Windows side on DrvFS mounts.
7. Windows `MoveFileEx` with `MOVEFILE_REPLACE_EXISTING`; not atomic across volumes.
8. Windows symlinks require Developer Mode or `SeCreateSymbolicLinkPrivilege`.
9. WSL2 has no native notification bridge; falls back to terminal bell.

## 3. Sandbox Per Platform

| Platform | Backend | Mechanism | Fail behaviour |
|----------|---------|-----------|----------------|
| Linux ≥5.13 | Landlock + seccomp | Landlock ruleset restricts FS paths; seccomp blocks dangerous syscalls | Fails closed (I-011) |
| Linux older | bubblewrap (bwrap) | User namespace + bind mounts + seccomp | Fails closed (I-011) |
| macOS | Seatbelt | `sandbox-exec` with generated SBPL profile | Fails closed (I-011) |
| Windows 11 | AppContainer + Job objects | Restricted token + capability SIDs; Job object for resource limits | Fails closed (I-011) |

All sandboxes:
- Default deny; allowlist paths/network targets per capability grant
- Cannot be weakened by agent; only user configuration can widen
- Probe at first-run / `kalash doctor` to confirm kernel support

## 4. Filesystem Divergence

| Issue | Linux | macOS (HFS+/APFS) | Windows (NTFS) |
|-------|-------|-------------------|----------------|
| Case | Sensitive (byte-oriented) | Insensitive-preserving; NFD normalization | Insensitive-preserving |
| Path separator | `/` | `/` | `\` (APIs accept `/`) |
| Max path | 4096 | 1024 | 260 (32767 with `\\?\` prefix) |
| Reserved names | None | None | CON, PRN, AUX, NUL, COM1-9, LPT1-9 |
| 8.3 names | N/A | N/A | Generated by default; affects glob patterns |
| Junctions / reparse | N/A | N/A | Junctions require special handling; ADS ignored |
| NFD | No normalization | Decomposes on write; compare with `unicodedata.normalize` | No normalization |
| Invalid bytes | Allowed (surrogateescape) | Disallowed | Disallowed |

Kalash handling:
- Normalize comparisons using `os.path.normcase` + NFD-aware equality on macOS
- Skip reserved names on Windows; warn user
- Use `surrogateescape` error handler on Linux for non-UTF8 filenames
- Never follow symlinks outside project root without explicit grant

## 5. Time

| Principle | Implementation |
|-----------|---------------|
| Storage: UTC only (I-038) | All DB columns, all JSON, all logs |
| Display: user's zone | Convert on render via `zoneinfo.ZoneInfo` |
| DST spring-forward | Scheduled 2:00 AM that doesn't exist → fire at next valid instant or skip (per `catchup_policy`) |
| DST fall-back | 2:00 AM that occurs twice → fire once at first occurrence |
| Monotonic clock | `time.monotonic_ns()` for durations and timeouts — immune to NTP jumps |
| Timezone database | stdlib `zoneinfo`; Windows requires `pip install tzdata` |
| Serialization | ISO-8601 with `Z` suffix: `2025-01-15T08:30:00Z` |
| Comparison | Always compare UTC timestamps; never compare formatted strings |

## 6. Configuration Validation

### 6.1 Layer Resolution Order

| Priority | Source | Scope |
|----------|--------|-------|
| 1 (lowest) | Built-in defaults | All |
| 2 | `~/.kalash/config.toml` | User |
| 3 | `<project>/.kalash/config.toml` | Project |
| 4 | `<project>/.kalash/config.local.toml` | Local (gitignored) |
| 5 | Environment variables `KALASH_*` | Process |
| 6 (highest) | CLI flags | Invocation |

### 6.2 Validation Rules

| Rule | Behaviour |
|------|-----------|
| Unknown keys | Warn and ignore (forward-compat) |
| Deprecated keys | Warn with migration hint |
| Type errors | Fail at load; refuse to start |
| Security keys (`secrets.*`, `trust.*`, `sandbox.*`) | User-scope only; project/local override forbidden |
| Invalid combinations | Fail with explanation |
| `sandbox_mode=read-only` + `network=true` | Valid — orthogonal axes |
| `sandbox_mode=none` + `approval_policy=never` | Invalid — rejected |

### 6.3 Commands

- `kalash config validate` — check all layers, report errors/warnings
- `kalash config show` — resolved effective config (secrets redacted)
- `kalash config set <key>=<value>` — write to user or project scope
- `kalash config path` — print resolved config file paths

## 7. Install Lifecycle

### 7.1 Installation Methods

| Method | Command | Notes |
|--------|---------|-------|
| uv (recommended) | `uv tool install kalash-code` | Isolated environment |
| pipx | `pipx install kalash-code` | Isolated environment |
| pip | `pip install --user kalash-code` | User site-packages |

### 7.2 First Run

| Step | Action |
|------|--------|
| 1 | Create `~/.kalash/` with mode `0700` |
| 2 | Initialize `kalash.db` with full schema |
| 3 | Run all migrations (idempotent) |
| 4 | Probe sandbox backend; record in `kv` |
| 5 | Prompt for initial provider credentials |
| 6 | Run `kalash doctor` equivalent checks |

### 7.3 Upgrade

| Step | Action |
|------|--------|
| 1 | Detect schema version vs code version |
| 2 | Auto-backup via `VACUUM INTO` |
| 3 | Apply pending migrations in order (I-022) |
| 4 | Re-probe sandbox (kernel may have changed) |
| 5 | Report any deprecated config keys |

### 7.4 Downgrade

**Not supported.** Forward-only migrations (I-022). User must restore a backup taken before the upgrade.

### 7.5 Uninstall

`kalash uninstall` removes:
- `~/.kalash/` (DB, blobs, models, plugins, logs)
- Orphaned OS keyring entries (prefixed `kalash:*`)
- Scheduled tasks / launchd plists / systemd units

Requires `--confirm` flag. Prints summary before acting.

## 8. Internationalization

| Aspect | Current state | Design for future |
|--------|---------------|-------------------|
| UI language | English only (v1) | No string concatenation; all user-facing strings in message catalog |
| Agent language | Responds in user's language natively (model capability) | — |
| Locale detection | `locale.getpreferredencoding()`, `LANG`, `LC_*` | — |
| Encoding | UTF-8 internally; `surrogateescape` for invalid filenames on Linux | — |
| String formatting | f-strings with named placeholders (translatable) | ICU MessageFormat for plurals |
| Date/number formatting | `babel` for display; internal always ISO-8601 / decimal | — |
| RTL support | TUI: not in v1; structured for future | Textual framework supports bidi |
| Error messages | English; error codes are locale-independent (`KALASH_*`) | Messages translatable; codes stable |
